📄 HTML 头部元素全解析

一份代码，掌握 <title> 、<base> 、<link> 、 <meta> 、<style> 、<script> 六大核心元素

🔖 <title> 必需

定义浏览器标签页标题 & 搜索引擎结果标题。每个页面必须有且仅有一个。

📌 当前页面标题：“HTML头部元素完全指南 - 初学者教程”

📍 <base> 可选

为所有相对 URL 设定基础路径。本页所有相对链接都将基于：

https://developer.mozilla.org/zh-CN/

⚡ 示例：下方链接 docs/Web/HTML 实际指向 MDN 的 HTML 文档。

🔗 <link> 可选

链接外部资源：CSS 样式表、图标、预加载、字体等。

  • ✅ 已链接外部 CSS（MDN 样式）
  • ✅ 已设置 favicon
  • ✅ 预加载字体（提升性能）
  • 🖨️ 已指定打印样式 (print.css)

🏷️ <meta> 可选

提供文档元数据：字符编码、视口、描述、关键词、作者、OG 标签等。

📝 页面描述：
“通过实际案例学习 HTML 头部元素：title, base, link, meta, script, style 的功能与用法。适合初学者快速掌握。”

🎨 <style> 可选

内部 CSS 样式，作用于当前页面。本页所有卡片、布局、配色均由 <style> 定义。

🖨️ 打印时，带有 .no-print 类的元素会被隐藏（演示 media 属性）。

⚠️ 打印时我会消失（.no-print）

⚡ <script> 可选

嵌入或引用 JavaScript，实现交互与动态功能。

  • 📦 已引用外部库（lazyload，带 defer）
  • 🧩 内联脚本已定义 window.APP_CONFIG
  • 📌 打开浏览器控制台查看日志

🧭 <base> 对相对链接的影响

👉 点击下方链接，观察地址栏 —— 所有相对路径都会自动加上 https://developer.mozilla.org/zh-CN/ 作为前缀：

  • 📘 docs/Web/HTML → MDN HTML 文档
  • 🎨 docs/Web/CSS → MDN CSS 文档
  • ⚡ docs/Web/JavaScript → MDN JavaScript 文档

💡 提示：所有链接均在新标签页打开（target="_blank" 由 <base> 设置）
